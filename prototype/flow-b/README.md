# Прототип флоу Б

HTML-прототип брокерского флоу Б — источник правды для библиотеки и макетов.

- `app.js`, `base.css`, `extra.css` — исходники (React 18 + htm, без сборщика)
- `build.py` — собирает их в один файл: `python3 build.py` → `sdelka-flow-b.html`
- `sdelka-flow-b.html` — готовая страница, открывается в браузере
